# 公开站点

仓库所有人已同意本仓库公开，并用 GitHub Pages 发布 `site/`。仓库与站点对任何人都可见。不要把私有订阅、访问令牌或密钥放进仓库或 `site/`。

# 声间 · 播客与每日灵感 MVP

零前端依赖，中文移动布局，HTML Audio 播放、快进/后退、倍速、进度及本机续播，公开 RSS 手动订阅，独立每日内容卡片，系统语音朗读标题。无 Apple 品牌资产。

## 本地运行

在项目目录执行 `python3 -m http.server 8080 --directory site`，打开 http://localhost:8080 。不要直接双击 HTML。更新：`python3 scripts/update.py`（Python 3.10+，标准库，无 API 密钥）。

## GitHub Pages 部署

1. 选择你拥有管理权限的目标仓库，确认其可见性及发布内容；本交付未创建或上传仓库。
2. 将本目录全部内容（包括隐藏的 `.github`）提交到 main 分支。
3. 仓库 Settings → Pages → Source 选择 GitHub Actions；允许工作流使用 Pages write 和 id-token write 权限。
4. 手动运行 Update and deploy，成功后使用任务输出的网址。支持 repository 子路径。

工作流每天北京时间 07:00 更新并直接部署 artifact，不向仓库回写；GitHub 定时任务可能延迟，长期不活跃公共仓库可能暂停计划任务。免费额度及私有仓库 Pages 可用性以账户计划为准。部署会公开 site 下全部内容，不能把私有订阅或访问令牌放入其中。

## RSS 与订阅

预置半拿铁 RSS https://proxy.wavpub.com/caffebreve.xml ，属于第三方代理地址，可能变化；版权属于节目作者。仅存标题、日期和音频地址，不重新托管音频。可在 sources.json podcasts 替换或添加 HTTPS RSS。更新任务不受浏览器 CORS 限制；前端手动订阅要求来源允许 CORS，失败时会明确提示，未使用公共跨域代理。手动订阅与进度只保存在当前设备，不跨设备同步。当前解析 RSS 2.0 enclosure，不支持 Atom、登录订阅与付费源。

## 每日 agent 架构与来源政策

sources.json → Actions 定时抓取 → 关键词筛选/URL 去重 → content.json → Pages 卡片。

这是无需模型费用的规则 agent，并未接入 LLM。articles 默认禁用：示例 Think with Google RSS 地址尚未核验，不会抓取。添加来源前必须确认发布者公开 RSS 的真实地址及再利用条款，仅使用允许展示的标题和原文链接；公开可访问不等于可复制全文。可采用你自己发布或明确授权的商业/营销 RSS。未配置时每日灵感显示空列表，不使用虚构新闻填充。

可选扩展：在 scripts/update.py 后增加独立服务端摘要任务，优先自有/明确许可文本，保留原文链接、时间和 AI 标记；将模型密钥配置为 GitHub Actions Secrets，仅在该步骤注入环境变量，禁止写入 JSON 或前端。对每次生成设条目数、token 与费用上限，抓取内容视为不可信输入，不能触发工具或修改任务指令。生产 TTS 同样仅在 Actions 生成授权摘要的音频，上传公开资产前核对权利；默认仅浏览器朗读标题，无服务端费用，系统语音可能依赖设备网络。

## 可靠性与限制

每源 25 秒超时、8MB 限制、单源失败保留输入快照中的该源内容并显示错误。Actions 每次从仓库初始快照启动，因此失败时回退到仓库快照，而非上一次部署；长期使用可另设持久化缓存或受控数据分支。

PWA 缓存同源页面及已读取数据，不缓存音频。离线可看已缓存列表，不能保证离线收听。iOS 可通过 Safari 分享菜单添加到主屏幕；安装能力依浏览器而异，正式上线建议补齐 192/512 PNG 图标。后台播放、锁屏行为受设备限制。浏览器播放错误会显示提示。未实现账号、搜索、订阅删除、云同步与完整离线下载。

已做 JavaScript 语法检查及真实 RSS 解析；未做真机、浏览器视觉或端到端播放验证。macOS Python 如出现证书错误请安装其受信任证书，不要关闭 TLS 校验。
